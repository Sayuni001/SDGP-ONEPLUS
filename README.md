
# One+ School

One+ School is a student-led Agile Team Project (ATP).

Our project aims to support rural schools in Sri Lanka by connecting verified schools with donors who wish to contribute essential educational resources.

## Key Features

- Verified school profiles
- Educational resource wishlists
- Physical-item donation offers
- Delivery tracking and confirmation
